Claude Code plugin & CLI

Type a topic. Get a Reel.

Topic2Reel turns one line of text into a ready-to-post 9:16 Instagram Reel: animated scenes, Hindi voiceover, music and a caption with hashtags. It runs on your machine, with no API key and no upload.

How it works

A topic, a spec, a video

  1. You give a topic

    “Study tips for exams”, for an audience you name. In Claude Code: /topic2reel:reel study tips for exams.

  2. Claude writes the spec

    Six scenes as JSON, following one prompt. A validator checks shape, length and script before anything renders.

  3. The engine renders

    A locked-down headless browser draws every frame, Piper speaks each line, ffmpeg mixes voice and music into one MP4 plus a caption file.

One scene of a spec

Scene length follows the length of the voice line, so you never retime anything by hand.

{
  "type": "hook",
  "headline": ["Raat bhar ratta", "mat maaro!"],
  "highlight": ["ratta", "mat"],
  "emoji": "📚", "stamp": "no",
  "badge": "Ratta system",
  "voice": "परीक्षा से पहले पूरी रात जागकर रटना बंद करो।"
}

Install

Plugin or command line

As a Claude Code plugin

/plugin marketplace add sahibsingh/Instagram-topic2Reel
/plugin install topic2reel@topic2reel
/topic2reel:reel study tips for exams

Written from Claude Code’s plugin docs; not yet tried against this repository. Local test: claude --plugin-dir ./Instagram-topic2Reel.

From the command line

pip install -r requirements.txt
npm ci && npx playwright install chromium
scripts/get_voice.sh hi_IN-pratham-medium
python3 engine/topic2reel.py --doctor
python3 engine/topic2reel.py examples/study_tips.json \
  -o out/study.mp4 --voice piper \
  --piper-model "$TOPIC2REEL_PIPER_MODEL"

Honest limits

What to know before you post

  • On-screen text is Roman script (Hinglish). Devanagari is used only for the spoken line.
  • Facts come from the LLM. Read health, money and legal topics before posting.
  • Voice quality depends on the Piper voice. English words can be mispronounced; re-spell them in Devanagari.
  • Private by design: the render browser has no network access (tested), the tool needs no API key, and child processes do not inherit your secrets.
  • Licences: piper-tts is GPL-3.0-or-later and each voice has its own licence. See SECURITY.md in the repository for the full review.
